# Modification Plans

本目录记录准备实施或正在实施的修改。一个计划应对应一个可独立验收的目标。

## Naming

文件名使用递增编号：`NNNN-short-name.md`，例如 `0001-eb-alfred-first-loop.md`。

## Required Sections

每个计划至少包含：

```text
# Title

Status: TODO | IN_PROGRESS | BLOCKED | DONE

## Goal
## Confirmed Decisions
## Open Questions
## Scope
## Out of Scope
## Tasks
## Acceptance Criteria
## Risks
```

计划完成后不删除。将状态改为 `DONE`，并链接对应的 `impl_docs/changes/` 记录。
