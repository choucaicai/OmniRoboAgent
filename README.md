# OmniRoboAgent

OmniRoboAgent 是面向具身 Agent 的模块化构建、运行与评估框架。

```text
Observe -> Plan -> Act -> Verify -> Update or Stop
```

当前实现包含同步 Runtime、可替换 Agent 组件、OpenAI-compatible LLM、OpenPI WebSocket policy 和 EB-ALFRED integration。
